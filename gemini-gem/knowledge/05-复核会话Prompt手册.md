# 知识文件 05｜复核会话 Prompt 手册（最大化 Gem 分析准确度与效能）

> 本文件是「会话侧指令」库：Gem 部署好后，在 chatbot 对话框里真正要敲进去的话。
> 它与 `instructions.md`（操作系统：角色/原则/流程）互补——指令框定义"它是谁、按什么规则做"，
> 本手册负责在每次对话里**激活深度思考、锁死证据链、压制幻觉、控制投喂节奏**，从而同时拉高准确度与效能。
> 直接复制对应段落到对话框使用即可；`＜...＞` 处替换为你的内容。

---

## 一、设计思路（4 个杠杆）

下面每条 Prompt 都围绕这 4 个杠杆来写：

| 杠杆 | 作用于 | 在 Prompt 里的体现 |
|---|---|---|
| **慢思考激活** | 准确度 | 显式要求内部先走「定位→引用→比对→定性」四步再输出，触发深度推理 |
| **证据强制锚定** | 反幻觉 | 每条结论必须带「页/表/段 + 原文引用」；无法定位的强制降级（呼应三态区分） |
| **分批 + 台账记忆** | 长文档效能 | 长文拆批投喂，维护"数据台账 + 问题池"，避免上下文挤爆后丢失早期发现 |
| **交付前自检 pass** | 准确度 | 出报告后再跑一轮反幻觉复核，统计"原文可佐证占比"，揪出臆断项 |

---

## 二、会话 Prompt 套件（按使用顺序）

### ① 启动指令 · 锁定坐标系 + 激活深度思考
> 每次新复核的第一句话。先逼它做 Gem 指令的"第 0 步"，不要一上来就喷全量报告。

```text
【本次复核启动】你现在是资深投行内核/质控负责人，对我接下来投喂的材料执行显微镜级 QC 复核。

请先只完成「第0步·锁定复核坐标系」，先别出全量报告：
1) 资产类型（产权类/特许经营权类，细分到产业园/IDC/高速/保租房…）——缺则从材料提取并向我确认；
2) 申报阶段（首次申报/反馈回复/扩募/定期披露）；
3) 本次材料范围（全文/节选；共几个文件；节选请标盲区）；
4) 复核侧重（默认全量 A→B→C）。

全程执行要求（贯穿后续每一条）：
- 慢思考：每条结论先在内部走完「定位→引用原文→比对→定性」四步再输出，不要跳步；
- 严格三态：✅确认错误 / ⚠️疑似待核 / ⛔材料缺失，三者不得混；"未见到"≠"不存在"；
- 零臆造：无法引用到确切页/表/段的，一律不得列为🔴硬伤，转入待核清单；
- 红线阈值一律以你知识库《03》为准，不确定的注明"请以最新《指引》复核"，禁止编造条款号。

请先回我第0步坐标系，并列出你接下来要重点检索的清单，等我确认后再进入模块A。
```

### ② 长文档分批投喂 · 维护台账与问题池
> 文档很长 / 分多个文件时用。这是**效能核心**——让它边读边沉淀，跨批勾稽才不会漏。

```text
【分批投喂 · 第 N / 共 M 批】以下是《文件名》第＿—＿页内容。
本批只做两件事，先别出最终报告：
1) 抽取关键数据点（金额/面积/机柜数/比例/年限/主体全称/各类基准日），存入累计「数据台账」表：｜指标｜数值｜单位｜出处(页/表)｜；
2) 记下本批内部可见的硬伤与疑点，挂入累计「问题池」。
每批结束请回显更新后的「数据台账」与「问题池」，便于后续跨批勾稽。继续等我投下一批。
```

### ③ 模块 A · 硬伤排雷（投喂完成后）

```text
【模块A·硬伤排雷】对已投喂的全部材料执行：
- 全局检索占位符/草稿痕迹/域代码：【】 [ ] XX ___ 待补充 MERGEFORMAT =SUM(ABOVE) "Error! Reference source not found"，逐个定位；
- 跨表勾稽：凡同一指标在两处以上出现（净利润/评估值/证券规模/基金规模/出租率…），一律"双引一算"——列A值、B值、差额与差%、配平口径，不许只说"前后不一致"；
- 单位串档（元/万元/亿元、㎡/万㎡、kW/MW）、时间口径、证照有效期是否早于报告日、主体名一致性（防张冠李戴的"幽灵主体"）。
按知识库《04》"模块一：致命低级错漏清单"表格输出，🔴>🟠 降序；每条必须含原文引用与出处，定位不到的转待核清单。
```

### ④ 模块 B · 业务逻辑与核心风险（先通用后专项）

```text
【模块B·穿透生死线与水分】先跑《01》模块B通用清单（权属/CoC债务限制/共用资产隔离/关联交易/现金流集中度），再叠加《02》中对应"〔本资产类型〕"的专项清单。
重点量化核验：
- 70%稳健性：近3年平均EBITDA/NCF 对比 未来3年预测均值，算出偏离%，超阈值要追问预测支撑；
- EBITDA→可供分配现金流调节桥是否完整、折旧利息加回是否合理；
- 回收资金用途是否触碰"严禁流入商品住宅/商业地产"红线；杠杆≤20%、战配≥20%及锁定期是否达标。
按《04》"模块二：估值与合规逻辑风险备忘"表格输出，每条给监管依据(《03》锚点)+问询预判+缓释方案。
```

### ⑤ 交付前自检 · 反幻觉复核（强烈建议每次都跑）
> 把准确度再抬一档的关键一步，专治"看着像问题、其实是脑补"。

```text
【交付前自检·反幻觉复核】对你上一条报告里的每一项🔴/🟠逐条自检，新增一列"证据强度"：
- 能否引用到确切原文页/表/段并复述关键字句？能→保留；不能→降级为⚠️并移入待核清单；
- 数值类问题是否已给出A/B两个出处+差额？缺则补齐，补不齐就降级；
- 是否把"我没投喂给你的材料"当成已确认事实？若有，标注"基于未提供材料的推断，需核实"。
最后给出统计：本报告中「原文可直接佐证」占比＿%、「依赖推断」占比＿%。占比异常请提示我补料。
```

### ⑥ 汇总出报告（分批投喂的收口）

```text
【汇总出报告】基于累计「数据台账」「问题池」及模块A/B/C结果，按知识库《04》完整模板出《质控复核报告》：
0.项目快照表 → 总评(🔴/🟠/🟡/🔵 各N项+一句话能否报送结论) → 模块一/二/三表格 → 附"待补充材料/待核实清单(⚠️⛔汇总)"。
跨批数据务必整体勾稽一遍再定稿，勿遗漏早期批次的疑点。
```

### ⑦ 模块 C · 话术重构（针对要改的具体段落）

```text
【模块C·风险闭环重构】对以下段落做"风险事实→中性专业表述→闭环解法"三段式改写，并去AI味：
"＜粘贴原文＞"
要求：① 规避内控一票否决敏感词（漏税/账实不符/转供电违规/内控失效…）；② 每个风险点后紧跟缓释解法(承诺函/对价扣减/保证金/照付不议/补办进度)；③ 删模糊指代(该/其/上述→写全称)与AI套话(综上所述/值得一提)；④ 定性改定量(给数字+来源)。
按《04》"模块三"表格输出：位置 | ❌原文 | ✅重构 | 重构理由。
```

## 三、增效短语库（可叠加到任意 Prompt 后）

随时把这些句子拼到上面任一条之后，按需微调行为：

- **要更狠的深度**：`这条很关键，请展开更长的逐步推理，并主动设想监管/投委会会怎么反向质疑。`
- **要更稳（防误报）**：`本轮宁可漏报不可错报，凡证据不足直接进⚠️待核，不要凑数。`
- **要更快（粗筛模式）**：`先只做15分钟快筛：仅列🔴致命硬伤，每条一行，暂不展开缓释方案。`
- **锁定口径**：`所有比例/年限红线请逐条对照《03》表格报出"材料值 vs 阈值"，不要凭记忆。`
- **防上下文丢失**：`回答前先回显当前「数据台账」摘要，确认你仍记得早期批次再继续。`
- **逼出处**：`凡没有"页/表/段"出处的结论一律删除或降级，不接受无源断言。`

## 四、准确度 ↔ 效能 取舍建议

| 场景 | 推荐流程 | 取向 |
|---|---|---|
| 短文档 / 节选 | ①启动 → 一次性贴全文 → ⑤自检 → ⑥出报告 | 最省事 |
| 长文档 / 多文件 | ①→②分批→③④分模块→⑤自检→⑥汇总 | 准确度最高 |
| 赶时间 | ①启动 + "粗筛模式"短语 → 先抓🔴 → 定稿前补⑤自检 | 一轮自检换回大部分准确度 |

> 平台档位：免费档上下文小，长文档复核建议用 **Pro / Ultra 档**；否则分批粒度要更细（每批控制在几千字内）。
