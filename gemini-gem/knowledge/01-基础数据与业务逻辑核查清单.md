# 知识文件 01｜基础数据与业务逻辑核查清单（模块 A + 模块 B 通用）

## 模块 A｜基础数据与低级错误核验（“硬伤排雷”）

### A1. 未清理的草稿痕迹与占位符
- 全局检索并定位所有未填写占位符：`【】` / `[ ]` / `XX` / `___` / “待补充”/“（此处略）”（涉及金额、面积、机柜数、比例、机构名称、开户行及账号、日期等开天窗项）。
- 检查表格残留 Word 域代码：`MERGEFORMAT`、`=SUM(ABOVE)`、`Error! Reference source not found`、交叉引用错位等。
- 检查模板套用痕迹：页眉页脚/水印残留他项目名称、字体字号不一致、批注与修订痕迹未接受、超链接指向外部草稿。

### A2. 前后数据与口径一致性（数据打架排查）——QC 重灾区
- **跨表勾稽**（逐项核对，列出数值对比）：
  - 利润表净利润 ↔ 财务指标汇总表净利润 ↔ 估值报告引用的净利润；
  - 资产负债表“待抵扣进项税额” ↔ 税务说明段落金额；
  - 评估值/交易对价 ↔ 招募书摘要 ↔ 资产支持证券规模 ↔ 基金募集规模；
  - 出租率 / 上架率 / 收费车流 等运营指标在“项目概况—尽调—评估—现金流预测”各处是否一致。
- **加总与尾差**：表内合计是否等于明细之和；四舍五入导致的 0.01 尾差是否配平；合并报表与单体口径勿混。
- **计量单位**：元 / 万元 / 亿元 / ㎡ / 万㎡ / kW / MW 是否串档；币种是否统一；百分比与小数是否混用。
- **时间口径与证照有效期**：
  - 统一用词（如全文用“截至”而非混用“截止”；“资产负债表日”“基准日”“评估基准日”口径一致）；
  - 引用资质/合同有效期是否**早于报告出具日**（证照已过期、保单失效、特许经营/租赁剩余年限与现金流预测期错配）；
  - 财务数据基准日、评估基准日、法律意见截止日是否自洽。
- **主体名称一致性（防“幽灵主体”）**：
  - 核查是否生硬套用他项目模板残留错误主体名（如本应为本项目主体却出现其他知名项目主体名称）；
  - 全称/简称首次定义后是否前后一致；统一社会信用代码、注册资本是否与工商一致；
  - 是否**遗漏关键业务主体**（运营管理机构、运营统筹机构、外部管理机构、原始权益人/发起人、ABS 计划管理人、基金管理人、专项计划等）。

### A3. 排版与标点规范
- 标点错误：`：：`、`。。`、中英文标点混用、括号不配对、全半角混用。
- 编号体系：章节/标题/表号/图号是否断层、重复、跳号或层级混乱；目录与正文页码是否对应；脚注/尾注引用是否错位。

## 模块 B（通用）｜合规与估值底层逻辑

> 先做本通用清单，再叠加《02-资产类型专项清单》（按资产类型择一执行）。

### B1. 基础资产合规性与权利限制（“生死线”测试）
- **权属与完整性**：土地/房产权证齐全、四至清晰、用途相符（仓储用地、商服用地、R4 等）；是否存在抵押、查封、租赁权对抗、未登记、划拨用地未补缴出让金等瑕疵；物理不可分割/共用资产是否说明并隔离。
- **立项与建设合规**：项目立项/核准/备案、规划许可、施工许可、竣工验收（含消防）齐全；高耗能项目（IDC 等）核查**固定资产投资备案 + 节能审查（能评）+ 环评**，并核实“批建相符”（实际建成规模/机柜数/容量与批复一致）。
- **重组摩擦与债务限制（CoC）**：底层银团贷款、融资租赁、债券等是否含**控制权变更（Change of Control）限制 / 资产处置限制 / 反稀释条款**；是否已取得债权人**无条件的平移/解除抵押/豁免同意函**；重组涉及的税负（土增、契税、增值税）是否测算并预留。
- **共用资产隔离**：未入池的共用设施（如 220kV 变电站、共用管廊、连廊、停车场）是否签署**排他性《共用资产使用协议》**并约定**公允分摊机制**（如按 IT 容量/建筑面积/计量分摊）；是否存在因共用导致的现金流/成本归集不清。
- **关联交易与同业竞争**：识别与原始权益人及关联方的租赁、采购、运营、托管交易，核查定价公允性与披露完整性；原始权益人/关联方是否存在同业竞争及**不竞争承诺**与隔离安排。
- **现金流来源分散度（1014 号文重点）**：单一最大租户/客户、关联方租金占比是否过高；过度集中的，是否充分披露并有缓释（照付不议、保证金、大股东兜底、替代客户预案）。

### B2. 财务与估值模型逻辑（“挤水分”测试）
- **70% 稳健性规则**：测算拟入池资产**最近 3 个会计年度平均 EBITDA（或经营性净现金流）是否 ≥ 未来 3 年预测平均值的 70%**；偏离过大需追问预测假设（出租率爬坡、租金增长率、CPI 联动）是否激进。
- **EBITDA / NCF 调节桥**：核查是否提供从净利润 → EBITDA → 可供分配现金流（NCF）的**完整调节桥表**；重资产项目折旧、摊销、利息是否准确加回，是否反映真实“造血”能力；非经常性损益是否剔除。
- **营运资金（NWC）与类债务扣减**：应付职工薪酬、静态/安全库存存货、应付未付工程款等是否作为“类债务”在**期初估值一次性扣减**，防止其在 DCF 经营期内被重复计为现金流而虚增估值。
- **能耗/电费净额法核算**：若电费成本显著偏低，核查大客户是否采用**净额法（代收代付/转供电）**结算；要求补充**专项会计政策披露**与合规性说明（转供电合规、电价加价合规），防范信审/审计质疑。
- **折现率与可比性**：WACC/折现率取值依据、Beta、风险溢价是否有支撑；资本化率与同类已上市 REITs/可比交易是否可比；终值/残值（产权类永续 vs 特许经营权到期归零）处理是否正确。
- **预测勾稽**：现金流预测的收入 = 单价 × 量 × 出租率，各驱动因子是否与尽调/合同/历史数据勾稽；资本性支出（大修、更新改造、机电更换）是否充分计提。

### B3. 资金流向与交易结构
- **净回笼资金定义**：是否严谨（评估值/交易对价 **扣除** 相关税费、偿还存量项目贷款、中介费用后的“净额”）；测算是否清晰可验。
- **回收资金用途合规（监管红线）**：用途是否符合“**主要投向新的基础设施补短板项目 / 符合国家政策方向**”，**严禁流入商品住宅、商业地产开发**等限制领域；补流等用途比例是否超限；是否有专户监管与承诺安排。
- **交易结构与杠杆**：“公募基金 + ABS + 项目公司”架构股债比、SPV 层级、税务穿透是否清晰；基金对外借款是否符合杠杆上限（**借款总额 ≤ 基金资产的 20%**，用途受限，以现行《指引》及扩募口径为准）。
- **战略配售与锁定**：原始权益人/同一控制下关联方战略配售比例（**合计 ≥ 20%**）及锁定安排（**自持 20% 部分锁定 60 个月、超出部分锁定 36 个月**）是否披露到位（以最新规则为准）。
